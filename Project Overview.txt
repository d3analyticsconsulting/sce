The purpose of this project is to accurately predict and forecast power grid failures across Southern California before they happen.

Because heat waves, surging demand, and wildfire threats make outages rare but high-stakes events, standard models tend to either miss real blackouts (False Negatives) or waste money sending crews out for false alarms (False Positives). This pipeline combines heavy-penalty machine learning models with an AI arbiter to catch real threats while filtering out the noise.

These are the steps that we took for this data project. We start by using Python (data.py) to simulate 36 months of regional power grid data across 100 Southern California ZIP codes, modeling normal energy loads alongside heat waves, wildfire risk, and power outages, and save it into a Databricks Delta table. From there (data_transform.py), we clean up the dates, build 1-month historical lag features to track past weather and grid strain, and split everything into chronological training, testing, and future forecast sets. Because missing an actual power outage (a false negative) is way more dangerous than dealing with a false alarm, we train three different machine learning models—Logistic Regression, Random Forest, and XGBoost—with heavy penalties (classification_model.py) so they catch as many potential grid failures as possible. Whenever those three models disagree on a borderline prediction, we send just those tricky conflict rows over to Groq’s Llama 3.3 70B model (skills.md) to act as a smart tie-breaker and weed out false alarms before crews are dispatched unnecessarily. Finally, a LangGraph workflow (groq_model.py) ties the whole pipeline together automatically, saving the audited grid failure predictions back to Unity Catalog so they're ready for DataBricks dashboard reporting.
